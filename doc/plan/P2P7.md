## Requirements

### Business Context

All newbuild vessels require approval from Classification Societies (DNV, ABS, Lloyd's Register, Bureau Veritas, Class NK). These organizations use portal-based submission systems. DocuRoute generates correctly formatted submission packages, allowing users to upload manually to society portals.

**2026 Reality Check**: Classification societies do NOT provide public REST APIs for bulk document submission. Portal-based upload is the standard industry practice. This is an **assisted submission** feature, not automated API integration.

### API Endpoints

Implement the following API routes in `apps/web/src/app/api/`:

1. **POST /api/classification-societies/configure** - Configure submission settings
   - Input: `{ classificationSocietyCode, defaultProjectCode, vesselImoNumber, coverSheetTemplate, fileNamingTemplate, fileNamingVariables }`
   - Permission: `CLASS_SOCIETY_CONFIGURE`

2. **GET /api/classification-societies/configurations** - List configurations
   - Returns: All company's society configurations
   - Permission: `CLASS_SOCIETY_VIEW`

3. **PATCH /api/classification-societies/configurations/{id}** - Update configuration
   - Permission: `CLASS_SOCIETY_CONFIGURE`

4. **POST /api/classification-societies/generate-package** - Generate submission package
   - Input: `{ classificationSocietyCode, projectId, packageTitle, submissionType, documentIds[], metadata }`
   - Returns: `{ submissionId, downloadUrls: { pdf, coverLetter, metadata, zip } }`
   - Permission: `CLASS_SOCIETY_GENERATE_PACKAGE`

5. **GET /api/classification-societies/submissions?projectId={id}** - List submissions
   - Query params: `status`, `classificationSocietyCode`
   - Permission: `CLASS_SOCIETY_VIEW`

6. **GET /api/classification-societies/submissions/{id}** - Get submission details
   - Permission: `CLASS_SOCIETY_VIEW`

7. **GET /api/classification-societies/submissions/{id}/download** - Get package download URLs
   - Returns: Presigned R2 URLs (7-day expiry)
   - Permission: `CLASS_SOCIETY_VIEW`

8. **PATCH /api/classification-societies/submissions/{id}/confirm** - Mark as manually submitted
   - Input: `{ classReferenceNumber, notes }`
   - Updates status to MANUALLY_SUBMITTED
   - Permission: `CLASS_SOCIETY_GENERATE_PACKAGE`

9. **POST /api/classification-societies/submissions/{id}/regenerate** - Re-generate package
   - Useful if documents updated after initial generation
   - Permission: `CLASS_SOCIETY_GENERATE_PACKAGE`

#### Generate Submission Package
```typescript
async function generateClassSocietyPackage(
  classificationSocietyCode: ClassificationSocietyCode,
  projectId: string,
  packageTitle: string,
  submissionType: SubmissionType,
  documentIds: string[],
  metadata: any,
  userId: string
): Promise<{
  submissionId: string;
  downloadUrls: {
    pdf: string;
    coverLetter: string;
    metadata: string;
    zip: string;
  };
}>;
```

**Behavior**:
1. Validate all documents are approved and watermarked
2. Get society configuration for company
3. Get appropriate PackageGenerator (DNV, ABS, LR, BV, NK)
4. Generate cover letter PDF with submission metadata
5. Apply society-specific file naming to each document
6. Combine all documents into single PDF with bookmarks/TOC
7. Generate metadata JSON with document codes, revisions, checksums
8. Bundle everything into ZIP file
9. Store all files in R2 with presigned URLs (7-day expiry)
10. Create ClassSocietySubmission record
11. Create audit vault entry
12. Send notification to document controller
13. Return submission ID and download URLs

#### File Naming
```typescript
function generateFileName(
  doc: Document,
  template: FileNamingTemplate
): string;
```

**Behavior**:
- Parse template string
- Replace variables: `{vesselCode}`, `{docType}`, `{docNumber}`, `{rev}`, `{date}`
- Apply society-specific formatting rules
- Return formatted filename

**Example Templates**:
- DNV: `{vesselCode}-{docType}-{docNumber}-R{rev}.pdf` → `PE2026-DWG-H1001-R02.pdf`
- ABS: `{imoNumber}_{docCode}_{date}.pdf` → `IMO1234567_ME-001_20260320.pdf`
- LR: `{projectCode}_{discipline}_{docCode}_Rev{rev}.pdf` → `HULL2026_ME_ME-001_RevB.pdf`
- BV: `{vesselName}_{docCode}_{rev}_{submissionType}.pdf` → `PacificExplorer_ME-001_02_APPROVAL.pdf`

## Quality Standards

Follow Phase 1 and Phase 2 patterns. Use TypeScript strict mode, Zod validation, transaction-wrapped operations, pdf-lib for document merging, PDFKit or React-PDF for cover letter generation.

### Performance
- PDF merging: <10 seconds for 50 documents
- ZIP creation: <15 seconds for full package
- **CRITICAL**: Use streaming for large PDFs (>100MB) - don't load entire file into memory
  ```typescript
  // Use streaming from R2 to avoid memory issues
  const stream = await getObjectStream(fileKey)
  // Pipe directly to response or ZIP
  ```
- Background job for packages >100 documents
- For classification society package creation, process documents in batches
- Add pagination for package history (default 50, max 100 per page)

### Security
- Validate only approved, watermarked documents
- Presigned URLs expire after 7 days
- Auto-delete packages after 30 days
- Log all downloads to audit trail
- Prevent cross-company package access
