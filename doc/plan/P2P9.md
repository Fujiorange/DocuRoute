# P2P9: Per-Project Storage Quota & Archival Pricing - Implementation Prompt

## Context

You are implementing **Phase 2, Prompt 9 (P2P9)** for **DocuRoute**, an ISO 9001 compliant document management system for shipbuilding, offshore platforms, and heavy industrial projects. DocuRoute is a pnpm monorepo with:
- **apps/web**: Next.js 14 app with NextAuth v4.24.13, TypeScript, Tailwind CSS
- **apps/worker**: Node.js BullMQ worker for background jobs
- **packages/db**: Prisma ORM with PostgreSQL (Supabase)
- **packages/core**: Shared business logic (no React/Next.js imports)
- **packages/types**: Shared TypeScript types
- **packages/emails**: React Email templates

**Phase 1 Status**: User authentication, PBAC authorization, document management, project management, custom roles, invitations, search, and notifications are fully implemented. Company model has basic tier management.

**Phase 2 Progress**: P2P1 (Equipment Hierarchy), P2P3 (Project Templates), P2P4 (Vendor Management), P2P5 (BIM Integration), P2P6 (Field Execution), P2P7 (Classification Society), and P2P8 (Audit Ledger) are complete.

**Your Mission**: Implement per-project storage quota management with archival pricing tiers (warm vs. cold storage), smart archival recommendations, user pinning, auto-restore for frequently accessed archived projects, and quota enforcement.

---

## Requirements

### Business Context

The current Phase 1 system has a hard 1.5 TB limit for PILOT tier. Large shipyards with multiple newbuilds will hit this ceiling within 3 projects. Archival tier allows long-term retention of older projects at lower cost (cold storage).

### Storage Tier Architecture

| Tier | Storage Type | Performance | Cost | Use Case |
|------|--------------|-------------|------|----------|
| **Warm** | Cloudflare R2 Standard | Instant access | Standard R2 pricing | Active projects (<24 months) |
| **Cold** | Cloudflare R2 Infrequent Access | 1-5 minute retrieval | SGD 0.10/GB/month | Archived projects (>24 months) |

### Core Business Logic

Implement in `packages/core/src/storage-quota.ts`:

#### Storage Calculation
```typescript
async function calculateProjectStorage(
  projectId: string
): Promise<number>; // Returns GB
```

**Behavior**:
```typescript
const documents = await prisma.document.findMany({
  where: { projectId },
  select: { fileSize: true, watermarkFileSize: true }
});

const totalBytes = documents.reduce((sum, doc) =>
  sum + (doc.fileSize || 0) + (doc.watermarkFileSize || 0), 0
);

return totalBytes / (1024 ** 3); // Convert to GB
```

#### Update Company Storage
```typescript
async function updateCompanyStorage(
  companyId: string
): Promise<{ warmGB: number; coldGB: number }>;
```

**Behavior**:
1. Fetch all projects for company
2. Calculate total warm storage (sum of projects with `storageTier = "WARM"`)
3. Calculate total cold storage (sum of projects with `storageTier = "COLD"`)
4. Update `Company.storageUsedWarmGB` and `storageUsedColdGB`
5. Return totals

#### Quota Enforcement
```typescript
async function checkStorageQuota(
  companyId: string,
  additionalGB: number
): Promise<{ allowed: boolean; quotaExceeded?: boolean; suggestedAction?: string }>;
```

**Behavior**:
1. Fetch company storage quota and usage
2. Check if `storageUsedWarmGB + additionalGB > storageQuotaWarmGB`
3. If exceeded:
   - Return `{ allowed: false, quotaExceeded: true, suggestedAction: "Archive old projects or upgrade plan" }`
4. Else:
   - Return `{ allowed: true }`

#### Smart Archival Recommendations
```typescript
async function getArchivalRecommendations(
  companyId: string
): Promise<ArchivalRecommendation[]>;
```

**Behavior**:
1. Fetch all warm projects for company
2. For each project:
   - Skip if `isPinned = true`
   - Check criteria:
     - `accessCount30Days = 0` AND `lastAccessedAt > 12 months ago`
     - OR `accessCount7Days < 5` AND `lastAccessedAt > 18 months ago`
3. Calculate potential savings: `storageUsedGB * (warmCost - coldCost)`
4. Sort by potential savings (descending)
5. Return top 10 recommendations

#### Archive Project
```typescript
async function archiveProject(
  projectId: string,
  userId: string
): Promise<{ jobId: string; estimatedCompletionMinutes: number }>;
```

**Behavior**:
1. Validate project is in WARM tier
2. Mark `Project.storageTier = "COLD"` and `archivedAt = now()`
3. Queue BullMQ job: `moveProjectToR2InfrequentAccess`
4. Log to StorageQuotaLog with action = "ARCHIVE"
5. Return job ID and estimated time

#### Restore Project
```typescript
async function restoreProject(
  projectId: string,
  userId: string
): Promise<{ jobId: string; estimatedCompletionMinutes: number }>;
```

**Behavior**:
1. Validate project is in COLD tier
2. Mark `Project.storageTier = "WARM"` and `archivedAt = null`
3. Queue BullMQ job: `moveProjectToR2Standard`
4. Log to StorageQuotaLog with action = "RESTORE"
5. Return job ID and estimated time

#### Auto-Restore for Frequently Accessed Archived Projects
```typescript
async function checkAutoRestore(
  projectId: string
): Promise<{ shouldRestore: boolean; reason?: string }>;
```

**Behavior**:
1. Check if project is archived (`storageTier = "COLD"`)
2. Check if `accessCount7Days > 10`
3. If true:
   - Return `{ shouldRestore: true, reason: "Project accessed 15 times this week" }`
4. Else:
   - Return `{ shouldRestore: false }`

#### Track Document Access
```typescript
async function logDocumentAccess(
  documentId: string,
  userId: string,
  accessType: DocumentAccessType
): Promise<void>;
```

**Behavior**:
1. Create DocumentAccessLog entry
2. Increment `Project.accessCount7Days` and `accessCount30Days`
3. Update `Project.lastAccessedAt = now()`
4. If project archived and `accessCount7Days > 10`:
   - Trigger auto-restore suggestion modal

### Performance
- **CRITICAL**: Storage calculation for large projects - use database aggregates NOT individual fetches:
  ```typescript
  // ✅ GOOD: Aggregate at database level
  const result = await prisma.document.aggregate({
    where: { projectId },
    _sum: {
      fileSize: true,
      watermarkFileSize: true
    }
  })
  const totalGB = ((result._sum.fileSize || 0) + (result._sum.watermarkFileSize || 0)) / (1024 ** 3)
  ```
