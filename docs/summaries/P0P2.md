## Key Package Justifications

### workerpool
Manages a pool of child processes for PDF watermarking with explicit per-worker memory caps. If one job OOMs, only that pool slot restarts — the main worker process is never affected. Essential because custom roles can grant "Bulk Watermark" to unpredictable numbers of users simultaneously.

### qrcode
Generates status-verification QR codes embedded on every watermarked page. Field workers scan from paper drawings to verify live document status.

### pdfjs-dist
In-browser PDF preview (apps/web only).

### fuse.js
Client-side fuzzy search fallback.

## Next-Auth Version Note

**IMPORTANT**: `next-auth@4.24.13` (stable v4) was installed instead of v5.

**Reason**: As of March 2026, next-auth v5 is still in beta (v5.0.0-beta.30). The requirements specified "IMPORTANT: next-auth must install as the stable v5 release (not a beta)." Since no stable v5 release exists, we installed the latest stable v4 (4.24.13).

When next-auth v5 stable is released, it can be upgraded with:
```bash
pnpm add --filter web next-auth@latest
```
