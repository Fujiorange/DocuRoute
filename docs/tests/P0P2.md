## 9. Verify Key Package Purposes

### workerpool
Used for managing a pool of child processes for PDF watermarking with explicit per-worker memory caps. If one job OOMs, only that pool slot restarts — the main worker process is never affected.

### qrcode
Generates status-verification QR codes embedded on every watermarked page. Field workers scan from paper drawings to verify live document status.

### pdfjs-dist (apps/web only)
In-browser PDF preview functionality.

### fuse.js
Client-side fuzzy search fallback.

## 10. Verify Excluded Packages

Ensure the following packages were NOT installed (as per requirements):
- `crypto-js` (should use SubtleCrypto + Node built-in crypto)
- `next-pwa` (should use `@ducanh2912/next-pwa` instead)

Run:
```bash
pnpm list crypto-js 2>&1 | grep "ERR_PNPM_NO_MATCH"
pnpm list next-pwa 2>&1 | grep "ERR_PNPM_NO_MATCH"
```

Expected: Both should show "ERR_PNPM_NO_MATCH" indicating they are not installed.

## 11. Build Test

Run a test build to ensure all dependencies are correctly installed:

```bash
cd /home/runner/work/DocuRoute/DocuRoute
pnpm install
pnpm typecheck
```

All packages should typecheck successfully.

## Expected Warnings

- Deprecated subdependencies warnings (fstream, glob, inflight, etc.) are expected and do not affect functionality
- Ignored build scripts warnings for @prisma/client, esbuild, sharp, etc. are expected in pnpm with certain security settings
- Playwright missing system libraries warning in CI environment is expected (browsers will work in headless mode)
